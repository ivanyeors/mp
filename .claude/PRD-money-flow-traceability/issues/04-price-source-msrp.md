# Slice 04 — Single price source: Costings MSRP -> storefront price (locked)

Type: AFK
Parent: PRD `money-flow-traceability` (`.claude/PRD/money-flow-traceability-prd.md`)
User stories covered: 4, 5, 6, 7, 8, 9

## What to build

Make Costings MSRP the single source of truth for the sell price, end to end: editing MSRP propagates to the storefront variant price, the variant cost, and the Stripe price, with the storefront price field locked.

- Migration: add `product_variants.price_key` (explicit costing link; resolves premium linen/fibrecool ambiguity).
- `price-sync` module: resolve price/cost from costing (`price_key` -> item MSRP -> pillow product), write `product_variants.price` (= MSRP) and `cost_price` (= computed BOM cost), then call the existing Stripe sync.
- Trigger the sync from the Costings save flow; populate `price_key` during inventory->ecommerce variant creation (drop the `price: 0` default).
- Make the storefront price field read-only in the product editor; the variant create/update API ignores client-sent `price`.
- Flag variants that cannot resolve a costing source.

## Acceptance criteria

- [x] Editing an MSRP in Costings updates the linked variant `price`, `cost_price`, and Stripe price in one save. (`costings/save/route.ts` calls `syncAllAutoGeneratedProductPrices` after upsert)
- [x] Premium pillow fabric variants (linen/fibrecool) resolve to the correct distinct MSRP via `price_key`. (`resolveVariantPrice` checks `price_key` first, then `pillow_product_id`)
- [x] The storefront variant price field is read-only; the variant API rejects/ignores client `price`. (UI `readOnly` + `isAutoGenerated` guard; API strips `price`/`cost_price` for auto-generated products)
- [x] Auto-generated pillow/bolster variants no longer default to $0; they reflect MSRP. (`inventory-sync.ts` calls `syncVariantPricesFromCostings` after variant creation; bolster variants set `price_key = 'product:bolster:{option1}'`)
- [x] Variants with no resolvable costing source are flagged in the products UI. (shows "⚠ No costing source" instead of "⚠ Price not set" on auto-generated products with $0 price)
- [x] `price-sync` has a test asserting correct resolution across `price_key`/`item_id`/`pillow_product_id` and the unresolvable case. (`lib/shop/__tests__/price-sync.test.ts`, 9 tests, all passing)
