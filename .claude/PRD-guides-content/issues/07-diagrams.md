## What to build

- Brief and commission, with a written licence:
  1. alignment set: side and back sleeper, each too high / about right / too low, neck line drawn, brand palette, no X-ray look;

  3. one OG image per guide, 1200×630.
- Deliver SVG or WebP at 2× with descriptive filenames. Add them to the Media library with alt text written for the information shown.
- Swap them into the guides' hero figures and sections.

## Acceptance criteria

- [ ] Licence on file; Media Assets carry alt text and provenance.
- [ ] `pnpm checks guides` passes (image paths exist, alt text present).
- [ ] Preview screenshots show each diagram legible at 390 px.
