## What to build

Add the two nouns this PRD introduces to `CONTEXT.md` so every later slice uses one name each.

The filling vocabulary in `CONTEXT.md` is already dense and precise — **Filling Template**, **Filling configuration**, **Placement**, **Section**, **sub-section**, **cell**, **Default Filling Template**, **Promote**, **Unpromoted configuration**. Two things this work relies on have no name yet:

- **Spatially authored** — whether a **Filling Template**'s **Placement** rows were laid out by a person or auto-generated by the 2026-07-24 backfill from a flat legacy recipe. Today every default template is the latter, and there is no word for it. The definition must state the operational test (occupies more than one **Section**), that it is derived rather than stored, and that a single-**Section** recipe is an import artefact rather than a valid build — so a future reader does not "fix" the warning by deleting it.
- **X-ray editor** — the editable **Placement** surface. It must be distinguished from the read-only preview x-ray shown to shoppers on the completed customisation preview, which shares the renderer but never gains edit affordances.

Place both beside the existing filling entries, following the file's shape: bolded term, definition prose with other glossary terms bolded and tables/routes in backticks, then an `_Avoid_:` line naming the collisions.

Collisions that matter:
- **X-ray editor** vs the read-only shopper preview x-ray (same component, different mode) and vs the retired 3×3 cell grid, which slice 06 deletes.
- **Spatially authored** must not be read as a stored column or a workflow state — it is computed from the placements themselves.
- "authored" must not blur with **Promote**, which turns an **Unpromoted configuration** into a catalog template.

Also record under `## Flagged ambiguities` the resolution that the ten left-packed templates are fixed by hand rather than by a migration, with the reason (an automatic re-spread would be a guess about a physical product, and a guess that looks authored is worse than an artefact that is labelled), so slice 07 does not relitigate it.

Demoable outcome: a reader who knows nothing about this PRD can read `CONTEXT.md`, use both terms correctly, and tell the **X-ray editor** apart from the shopper preview.
