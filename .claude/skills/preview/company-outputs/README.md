Made-up agent outputs for the preview of the Company page (Analytics →
Company). The preview starts the app with COMPANY_OUTPUTS_DIR pointing here,
so the page reads these instead of Google Drive. Same layout as the Drive
folder "Agents": YYYY/YYYY-MM for reports and drafts, _trackers for CSVs. A
`.gdoc` file stands for a Google Doc and is read the way Drive exports one.
Every name, number and finding here is invented.
